**PulsE** — это стильный тёмный веб-мессенджер.  
Бесконечная лента, сторис, музыка, чат и социальные связи — всё в одном месте с невероятным дизайном.
---

## Основные возможности

### Вступительная страница
- Красивая авторизация и регистрация
- Плавные переходы, тёмная тема из коробки
- Валидация форм + анимации успеха/ошибок

### **Мессенджер**
- Чат в реальном времени (WebSocket)
- Поиск пользователей, эмодзи, реакции, вложения
- Голосовые сообщения и видео-звонки

### Друзья
- Отдельная вкладка и страница «Друзья»
- Поиск, предложения, онлайн-статус

### Бесконечная лента
- Посты с фото/видео
- Лайки, репосты, сохранения
- Бесконечная прокрутка (Infinite Scroll)
- Ваши любимые сторисы

### Комментарии
- Вложенные ответы
- Реакции на комментарии
- Анимация появления

### Музыкальный плеер
- Встроенный плеер с красивым визуализатором
- Плейлисты прямо в ленте
- Мини-плеер в нижней панели (как в Spotify)

### Сторис
- Круговые аватарки
- Просмотр сторис с прогресс-баром
- Добавление своих сторис

### Дизайн
- Полностью тёмная современная тема (`#0a0a0a` + неоновые акценты)
- Плавные анимации (Framer Motion)
- Адаптив под все устройства
