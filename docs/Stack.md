#### Backend (Java Spring)

- **Spring Security + JWT + OAuth2:** Полная безопасность.
- **Spring Data JPA + Hibernate:** Работа с пользователями, настройками, списком чатов.
- **Sprint Cloud Gateway**
- **Spring WebSocket:** Реалтайм транспорт.
- **Spring Cloud Stream:** Для интеграции с Kafka/RabbitMQ (асинхронная обработка очередей, например, отправка уведомлений или трансляция сообщений).
- **Media Storage - MINIO:** Хранение картинок, музыки, аватарок. MinIO ставится локально (Docker).
- **Search Engine** - Elasticsearch / Opensearch Мгновенный полнотекстовый поиск по сообщениям и музыке. Postgres не справится с нечетким поиском на больших объемах.
- **Flyway:** Версионирование БД.

#### Frontend (React)

- **React Query (TanStack Query):** Управление кэшем сообщений. Когда приходит событие по WebSocket, вы обновляете кэш, и UI перерисовывается.
- **Framer Motion:** Плавные анимации появления сообщений (как в Telegram — "всплывание").
- **PWA (Progressive Web App):** Чтобы сайт работал как приложение, мог отправлять уведомления даже когда вкладка закрыта (Push API).
- **WebRTC:** Для реализации голосовых звонков прямо в браузере (Peer-to-Peer соединение).

#### Database (PostgreSQL)

- **JSONB:** Хранение метаданных сообщений (реакции, упоминания) внутри колонки `jsonb`. Это быстрее и гибче, чем отдельные таблицы для реакций.
- **Partitioning (Секционирование):** Таблица сообщений будет огромной. Разделите её по датам или ID серверов, чтобы база не "упала".
- **Full Text Search (tsvector):** Встроенный поиск по сообщениям (Postgres умеет искать очень быстро без Elasticsearch).
