#### 5. Notification Gateway
Сервис-"подписчик", ни от кого не зависит, кроме Kafka.

- **Ответственность:**
    - Доставление уведомлений, если юзер оффлайн.
    - Агрегация уведомлений (не спамить 100 пушей за секунду).
    - Каналы доставки: Firebase (FCM), APNs (Apple), Email (SMTP), SMS (Twilio).
- **Технологии:**
    - Spring Boot + Kafka Consumer.
    - Внешние SDK (Firebase Admin SDK).
- **Интеграция:**
    - Слушает **ВСЕ** события: `MessageSent` (из Messaging), `SpaceStarted` (из Space), `NewRelease` (из Media).

### 5.1. Управление устройствами (Devices)

#### Таблица: `user_devices`

Хранит токены устройств (Firebase, APNs) для отправки Push-уведомлений. Один пользователь может иметь много устройств (телефон, планшет, браузер).

| Поле             | Тип данных     | Описание                                                                 |
| ---------------- | -------------- | ------------------------------------------------------------------------ |
| **id**           | `BIGSERIAL`    | Primary Key (PK).                                                        |
| **user_id**      | `BIGINT`       | ID пользователя (Identity Service).                                      |
| **device_token** | `VARCHAR(255)` | Уникальный токен устройства (FCM Token / APNs Token). Уникальный индекс. |
| **device_type**  | `VARCHAR(20)`  | Тип устройства: `ANDROID`, `IOS`, `WEB`.                                 |
| **user_agent**   | `VARCHAR(255)` | Информация об устройстве/браузере ("Chrome on Windows", "iPhone 15").    |
| **is_active**    | `BOOLEAN`      | Активен ли токен (если отправка не удалась, ставим false).               |
| **created_at**   | `TIMESTAMPTZ`  | Дата регистрации устройства.                                             |

### 5.2. Хранение уведомлений (History)

#### Таблица: `notifications**

История всех сгенерированных уведомлений. Нужна для отображения "колокольчика" в приложении.

|Поле|Тип данных|Описание|
|---|---|---|
|**id**|`BIGSERIAL`|Primary Key (PK).|
|**user_id**|`BIGINT`|Кому адресовано (Identity Service). Индекс.|
|**type**|`VARCHAR(50)`|Тип: `NEW_MESSAGE`, `NEW_LIKE`, `FRIEND_REQUEST`, `SYSTEM`.|
|**title**|`VARCHAR(255)`|Заголовок уведомления.|
|**body**|`TEXT`|Текст уведомления.|
|**data**|`JSONB`|Payload с данными для навигации (например, `{"chat_id": 123}`).|
|**is_read**|`BOOLEAN`|Прочитано ли. Индекс (для счетчика непрочитанных).|
|**read_at**|`TIMESTAMPTZ`|Время прочтения.|
|**created_at**|`TIMESTAMPTZ`|Время создания.|

### 5.3. Настройки и Подписки (Settings)

#### Таблица: `notification_settings**

Гибкие настройки пользователя (от чего отписаться, что оставить).

| Поле             | Тип данных     | Описание                               |
| ---------------- | -------------- | -------------------------------------- |
| **id**           | `BIGSERIAL`    | Primary Key (PK).                      |
| **user_id**      | `BIGINT`       | ID пользователя. Уникальный.           |
| **push_enabled** | `BOOLEAN`      | Глобальное включение/выключение пушей. |
| **new_message**  | `BOOLEAN`      | Уведомлять о новых сообщениях.         |
| **new_follower** | `BOOLEAN**     | Уведомлять о подписчиках.              |
| **marketing**    | `BOOLEAN**     | Разрешена ли рекламная рассылка.       |
